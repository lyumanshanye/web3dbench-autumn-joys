Build a standalone Three.js browser app called “Intro Stage Lab.” Use only locally available Three.js code and procedural geometry/materials; load no models, textures, fonts, animation libraries, or remote assets. Use Y-up world units and numeric tolerance 1e-5. Expose `window.introLab` with `scene`, `camera`, `renderer`, `stageRoot`, `emblem`, `titleBars`, `beacons`, `setFrame(f)`, `focusSelected(id)`, `projectBeacon(id)`, `pickAt(clientX, clientY)`, `reset()`, and `getState()`.

1. Render a full-window scene with background `0x101018`, a `PerspectiveCamera(50, aspect, 0.1, 200)`, ambient light, and directional light. Initially place the camera at `(0,6,14)` looking at `(0,0,0)`. Add a 20×0.2×16 ground box centered at `(0,-0.1,0)`. Create `emblem` as a group at `(-3,-4,-20)` containing a torus with radius 1, tube 0.25, and 32 radial segments. Create `titleBars` at `(3,0,0)` containing three separate 3×0.35×0.5 boxes centered at local Y values 0, 0.7, and 1.4.

2. Add exactly three pickable beacon meshes to `beacons`, each a 0.8-radius, 1.5-high cylinder: `left` at `(-6,0.75,2)`, `core` at `(0,0.75,-4)`, and `right` at `(6,0.75,2)`. Give every beacon a unique non-black material color. Canvas pointer clicks must raycast only these beacons, select the first hit, and call `focusSelected` with its ID. Selection must set that beacon’s material emissive color to `0xffffff` and emissive intensity to 0.35 while clearing this highlight on the others.

3. Implement a 30-fps timeline from frame 0 through 120. `setFrame(f)` must round finite input to the nearest integer, clamp it to `[0,120]`, update the scene immediately, and return the resulting frame; non-finite or non-numeric input returns the current frame without changing anything. Define `a=min(frame/15,1)` and `b=min(frame/30,1)`. Set `emblem.position` to `(-3,-4+4*a,-20+20*b)` and uniformly scale `titleBars` by `1+0.25*a`. In `tour` mode, set camera position to `(0,6,14-7*min(frame/60,1))` and look at the origin. Rendering may continue, but time must not advance the frame automatically.

4. `focusSelected(id)` accepts only `left`, `core`, or `right`; for a valid ID it selects that beacon, changes mode to `focus`, positions the camera at beacon position plus `(0,3,5)`, and looks at the beacon center. It returns `true`. An invalid ID returns `false` and changes nothing. `projectBeacon(id)` returns `{x,y,z}` containing that beacon center in current-camera normalized device coordinates, or `null` for an invalid ID. `pickAt(clientX,clientY)` performs the same picking as a canvas click using the renderer canvas bounding rectangle and returns the selected ID or `null`.

5. Provide Frame, Mode, and Selected text readouts plus Step and Reset buttons. Step calls `setFrame(currentFrame+1)`. `reset()` restores frame 0, `tour` mode, no selection, all default highlights, the initial camera, and all timeline transforms. `getState()` returns `{frame,mode,selectedId,cameraPosition,cameraTarget,emblemPosition,titleScale}` with numeric arrays for positions and a numeric scale. Resizing updates camera aspect and renderer size without altering frame, mode, selection, or camera target.
