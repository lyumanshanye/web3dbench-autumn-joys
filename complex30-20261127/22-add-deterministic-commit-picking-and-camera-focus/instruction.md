Extend the existing repo-surf browser app with commit picking and a deterministic offline inspection mode. Preserve the existing branch geometry, commit pooling, playback, and normal repository-loading flow except where specified.

1. Add a fixture mode activated by the exact query string `?fixture=picking`. It must bypass repository fetching and the loading screen, make no network requests, and render one linear branch containing five commits in newest-first order. Their full SHAs are 40 repetitions of `a`, `b`, `c`, `d`, and `e`, respectively; their messages are `commit A` through `commit E`. Each commit except the oldest has the next SHA as its only parent, and the oldest has no parents. Use the existing layout code and configuration for their world positions.

2. Make rendered commit objects pointer-pickable. Set `userData.commitSha` to the full SHA on each Commit root. Clicking a visible commit must select exactly that commit, using the nearest intersection when hits overlap. Show a DOM panel with `data-testid="commit-inspector"` and child fields `data-testid="inspector-sha"`, `inspector-message`, and `inspector-index`; display the full SHA, complete message, and zero-based commit index. Hovering a pickable commit must set the canvas cursor to `pointer`, and leaving it must restore the previous cursor.

3. Expose selection spatially: the selected Commit root's local scale must be `[1.5, 1.5, 1.5]`, while every unselected root remains `[1, 1, 1]`. On selection, immediately move the camera to world position `P + (0, 6, -10)`, where `P` is the selected commit's world position, set `camera.up` to `(0, 1, 0)`, and look directly at `P`. While a commit remains selected, CameraOperator must not overwrite these camera values, although track playback may continue.

4. Pressing Escape, clicking empty canvas space, or calling the reset API below must clear the selection and hover state, remove the inspector, restore all commit scales to 1, and hand camera control back to the existing CameraOperator. It must not reload the page, reset the commit fixture, or restart the playback clock.

5. In fixture mode only, expose `window.__repoSurfPicking` after the scene is ready. `getState()` must return `{selectedSha, commits, camera}`, where commits contain `{sha,message,index,position}` in newest-first order and camera contains numeric `position`, `target`, and `up` triples. `projectCommit(sha)` must return that commit's current world position projected with the live camera as `{x,y,visible}`, with x/y in normalized device coordinates and visible indicating NDC bounds `[-1,1]` on all axes. `reset()` performs requirement 4. Unknown SHAs must return null without changing state. Do not expose this API outside fixture mode.

6. Keep ordinary URLs on the existing fetch/loading experience. All fixture behavior must work from local source and bundled assets without external services, and no requirement depends on screenshot comparison.
