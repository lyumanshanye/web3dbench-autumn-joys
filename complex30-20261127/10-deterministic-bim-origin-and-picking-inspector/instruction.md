Build a standalone Three.js browser app called “BIM Origin Inspector.” Use only local Three.js code, procedural BoxGeometry, and solid-color materials; make no runtime network requests and load no models, textures, fonts, controls libraries, or remote data. Use meters, Y-up coordinates, an 800×600 canvas, and numeric tolerance 0.0001. Expose `window.bimOriginLab` with `scene`, `camera`, `renderer`, `modelRoot`, `objects`, `bounds`, `origin`, `selectedId`, `setTypeVisible(type, visible)`, `pick(ndcX, ndcY)`, `focusSelected()`, `reset()`, and `getState()`.

1. Create exactly four meshes from this inline fixture, storing each mesh in `objects` and setting `mesh.name` and `mesh.userData.id` to its ID and `mesh.userData.type` to its type: `wall-A`, IfcWall, center `[-4,1,0]`, size `[2,2,4]`; `slab-A`, IfcSlab, center `[0,0.5,0]`, size `[6,1,6]`; `window-A`, IfcWindow, center `[3,2,-1]`, size `[1,4,2]`; `beam-A`, IfcBeam, center `[0,4,3]`, size `[8,2,2]`. Sizes are full width, height, and depth. Put every mesh directly under `modelRoot`, using the listed centers as local positions.

2. Set `bounds` to `{min:[-5,0,-3], max:[4,5,4]}`. Compute the bounds center componentwise as `(min+max)/2`, set `origin` to its negation, and copy that vector to `modelRoot.position`; thus origin is `[0.5,-2.5,-0.5]`. Keep mesh local positions unchanged. Use a PerspectiveCamera with vertical FOV 40 degrees and aspect 4/3. Let `diagonal` be the bounds diagonal length, set `camera.far = diagonal*5` and `camera.near = camera.far/1000`. The initial camera position is `[12,9,14]`, looking at `[0,0,0]` with up `[0,1,0]`.

3. Implement `pick(ndcX,ndcY)` with `THREE.Raycaster.setFromCamera` using the current camera. Consider only meshes whose own `visible` property is true, choose the nearest intersection, set `selectedId` to its ID, and return that ID. Return null and clear selection when nothing is hit. Give only the selected mesh a green emissive highlight (`0x00ff00`, intensity 1); restore every unselected mesh to emissive black with intensity 0. Canvas pointer clicks must convert the canvas-relative position to NDC and call this same function.

4. Implement `setTypeVisible(type,visible)` by changing every mesh of exactly that IFC type and returning true. For an unknown type, return false without changing visibility or selection. Hiding the type containing the selected mesh must clear its selection and highlight. Initially all types are visible.

5. Implement `focusSelected()` to return false when nothing is selected. Otherwise compute the selected mesh’s world-axis-aligned bounding-box center as `target`, set `distance = (diagonal/2)/Math.tan(20*Math.PI/180)*1.25`, place the camera at `target + normalize([1,0.75,1])*distance`, make it look at `target`, update its matrices, and return true. Do not alter FOV, near, far, model transforms, or visibility.

6. Provide Focus and Reset buttons. `reset()` must restore the initial camera pose and clipping values, all-type visibility, origin, mesh transforms and materials, and clear selection. `getState()` must return selectedId, origin, camera position and current look target, near, far, and a visibleTypes map for the four fixture types.
