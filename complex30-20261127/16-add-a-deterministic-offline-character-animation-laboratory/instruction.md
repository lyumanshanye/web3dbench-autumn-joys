Extend the existing browser client with an offline **Animation Lab** while preserving the current Play, Settings, Quit, and multiplayer join behavior.

1. Add an `Animation Lab` button to the main menu. Activating it must hide the menu and open a new local module without calling `joinGameUrl`, creating a connector, or making any network request. Provide a `Back to menu` control that disposes the lab renderer, cancels its animation frame, removes lab DOM, and restores the original menu. Use the repository's local Three.js import map and procedural geometry only.

2. Build a Y-up scene with a ground grid on XZ and a perspective camera at `(6,4,8)` looking at `(0,1,0)`. Create a hierarchy named `actor`, `torso`, `head`, `upperArmL`, `upperArmR`, and `ball`; also store each name in `userData.nodeId`. `actor` starts at `(0,0,0)`. Its children are: a `0.8 x 1.0 x 0.4` torso box centered at `(0,1.2,0)`; a radius-`0.3` head sphere at `(0,2,0)`; arm pivot groups at `(-0.55,1.55,0)` and `(0.55,1.55,0)`, each containing a `0.2 x 0.8 x 0.2` box centered at local `(0,-0.4,0)`; and a radius-`0.25` ball at `(0,1.1,0.55)`. Expose the scene, camera, actor, and a `sampleClip(time)` function on `window.animationLab` for inspection.

3. Define one inline clip with duration `4` seconds and linear interpolation between these keys: `actor.position.y` is `0, 0.25, 0, 0.25, 0`; `upperArmL.rotation.x` in degrees is `0, -60, 0, 60, 0`; and `upperArmR.rotation.x` is `0, 60, 0, -60, 0`, at times `0, 1, 2, 3, 4` respectively. Convert degrees to radians only when assigning rotations. Between keys use `value = a + (b-a)*(time-ta)/(tb-ta)`. Sampling must change only these three channels, leaving all other local transforms unchanged. Thus at `t=1.5`, root Y is `0.125`, left X rotation is `-30` degrees, and right X rotation is `30` degrees.

4. Provide Play/Pause, Reset, Step, a speed selector with `0.5`, `1`, and `2`, a numeric time input, and Set Time. Start paused at `t=0` with speed `1`. During playback accumulate at most `0.25` seconds of real frame delta, advance in fixed `1/120`-second simulation steps multiplied by speed, and wrap playback time modulo `4`. Pause must prevent time changes. Step is allowed only while paused and advances exactly `1/120` seconds, wrapping modulo `4`. Reset pauses, sets time to `0` and speed to `1`, samples the clip, and clears lab output/error text without changing saved game settings. Display time to three decimals.

5. Set Time accepts finite numeric values from `0` through `4`, inclusive, pauses playback, and samples that exact time; paused `t=4` must show the endpoint rather than wrapping. Empty, nonnumeric, NaN, infinite, or out-of-range input must leave time, pose, speed, and play state unchanged and display `Invalid time` in a dedicated status element.

6. Add `Export samples`, which writes JSON into a lab textarea with schema `{"duration":4,"sampleRate":30,"samples":[...]}`. Generate exactly `121` samples for `i=0..120`, each `{ "time": i/30, "actorY": ..., "leftArmXDeg": ..., "rightArmXDeg": ... }`, sampling independently without changing current playback state or time. Round every exported number to six decimal places. The exported data must reproduce the linear keys and include the unwrapped endpoint at time `4`.
