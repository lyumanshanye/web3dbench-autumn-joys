Build a standalone Three.js browser app called “Scroll Chair Studio.” Use only local starter dependencies and procedural geometry; make no runtime network requests. Use meters, Y-up coordinates, degrees for rotation inputs, and numeric tolerance 1e-5. Expose `window.chairStudio` with `scene`, `camera`, `renderer`, `controls`, `chairRoot`, `upholstery`, `getState()`, `setScroll(p)`, `setColor(id)`, `setRotation(degrees)`, `enterCustomize()`, `exitCustomize()`, `save()`, `load()`, `importState(text)`, and `reset()`.

1. Create a responsive canvas, ambient and directional lighting, a 12×12 ground plane at y=0, and a PerspectiveCamera(45, aspect, 0.1, 100). Build `chairRoot` with a seat BoxGeometry(2,0.3,1.8) named `seat` at (0,1,0), a back BoxGeometry(2,1.8,0.25) named `back` at (0,1.9,-0.775), and four BoxGeometry(0.18,1,0.18) legs at x=±0.8, z=±0.65, y=0.5. Seat and back must share one MeshStandardMaterial named `upholstery`; legs use a separate dark material. Initial color is green #96b2a1, rotation is 0, and mode is browse.

2. In browse mode, controls are disabled and `setScroll(p)` clamps finite p to [0,1], then positions the camera by piecewise linear interpolation while targeting (0,1,0). For 0≤p≤0.5, interpolate from (0,2,6) to (0,1.5,3.25) using u=2p. For 0.5<p≤1, interpolate from (0,1.5,3.25) to (-3,1.5,0) using u=2p-1. Non-finite p returns false without mutation; valid calls return true. Provide a range input min=0, max=1, step=0.001 wired to this method.

3. `enterCustomize()` sets mode to customize, enables OrbitControls targeting (0,1,0), and places the camera at (-1.95,2.54,2.29). `exitCustomize()` returns to browse, disables controls, and recomputes the camera from the retained scroll value. `setRotation(degrees)` clamps finite input to [-45,45] and sets `chairRoot.rotation.y` to that angle in radians; non-finite input returns false without mutation. `setColor(id)` accepts only green #96b2a1, red #a57d7d, or violet #aa83aa, updates the shared upholstery material, and returns true; unknown IDs return false without mutation. Add Customize, Exit, and three labeled swatch buttons.

4. `getState()` returns `{version:1,mode,scroll,colorId,rotation,cameraPosition,target,controlsEnabled}`, with cameraPosition and target as three-number arrays and rotation in degrees. `save()` writes that state, excluding derived camera fields and controlsEnabled, to localStorage key `scroll-chair-studio-v1` as JSON with exactly version, mode, scroll, colorId, and rotation, and returns the JSON string. `load()` returns false without mutation if no save exists; otherwise it applies a valid save, derives the appropriate camera and controls state, and returns true.

5. `importState(text)` accepts the same five-field JSON schema. Reject malformed JSON, wrong version, non-finite or out-of-range scroll/rotation, unknown mode/colorId, or non-number numeric fields by returning false with no state or scene mutation. Valid imports return true and update the scene. `reset()` removes the saved key and restores browse mode, scroll 0, green, rotation 0, and the initial camera; it does not reload the page.
