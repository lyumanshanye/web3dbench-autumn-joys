Extend the existing demo with an offline, deterministic Three.js visualization without changing the existing track-selection, server-fetch, Mapper, or audio-driven visualization behavior.

1. Add a `Run Fixture` button with ID `fixture-btn` beside the existing GO button. Clicking it must call the existing `destroy()` flow, then start the new visualization directly in `#viz-container`; it must not require a selected track, load audio, instantiate Mapper, or make any network request. Add a `Fixture Lattice` option to the visualization selector only if useful for integration, but the button must always work.

2. Implement a visualization class with `start()`, `setTime(t)`, `play()`, `pause()`, `getState()`, and `destroy()` methods, and expose the active instance as `window.fixtureViz`. Its scene must contain a group named `fixture-root` and nine unit BoxGeometry meshes named `cell-r-c` for rows and columns 0–2. For cell `r,c`, use local position `x=(c-1)*2`, `z=(r-1)*2`, and feature index `j=(r*3+c)%3`. Use a PerspectiveCamera at `(8,8,8)` looking at the origin. Do not load models, textures, or other assets.

3. Embed exactly this feature timeline, with times 0, 1, 2, and 3 seconds: `F0=[0,0.25,0.5]`, `F1=[0.5,0.75,1]`, `F2=[1,0.5,0]`, `F3=[0.2,0.4,0.6]`. At time `t`, linearly interpolate adjacent frames with `a=t-floor(t)`; at `t=3`, use F3. For every cell compute `v` from its feature and set `scale.y=h=0.5+2*v`, `position.y=h/2`, and leave `scale.x=scale.z=1`. Thus every box bottom remains at local y=0. Set `fixture-root.rotation.y=t*Math.PI/4`.

4. Starting or rerunning the fixture must reset time to 0 and render that state. `setTime(t)` must immediately render, clamp finite values below 0 to 0 and above 3 to 3, and return the clamped time. For `NaN`, Infinity, a missing argument, or a non-number, it must throw `TypeError` without changing time or the scene. `getState()` must return `{time, heights, rotationY}`, where `heights` is a nine-element array in row-major cell order.

5. The fixture must not advance autonomously after `start()`. `play()` advances from the current time using elapsed monotonic clock time, stops at 3 seconds, and `pause()` freezes the current time. Repeated `play()` calls while already playing must not create additional animation loops. `destroy()` must cancel animation, remove the renderer canvas, dispose fixture geometry and materials, and clear `window.fixtureViz` if it references that instance.

6. Rerunning via `fixture-btn` must leave exactly one fixture canvas and nine fixture cells. Existing non-fixture visualizations must continue through their original audio and Mapper path, and switching away from the fixture must invoke its cleanup. Keep all fixture data and code local so this mode works with the server unavailable.
