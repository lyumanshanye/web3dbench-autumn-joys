Extend the existing viewer without changing its normal model-loading, orbit-control, rendering, or drag-and-drop behavior. Add an opt-in diagnostic mode activated by the URL query `?picking-fixture=1`.

1. In fixture mode, do not load a GLB. Create a `Group` named `picking-fixture` containing three logical pick groups, each with the stated `userData.pickId` and one child `Mesh` using `BoxGeometry` and a `MeshStandardMaterial`: `rear` has dimensions (2,2,2), world position (0,0,-2), and child name `rear-surface`; `front` has dimensions (1,1,1), world position (0,0,1), and child name `front-surface`; `offset` has dimensions (1,1,1), world position (3,0,0), and child name `offset-surface`. Use a `PerspectiveCamera` with FOV 60 degrees, aspect 4/3, near 0.1, far 100, position (0,0,12), looking at the origin. Set the orbit target to the origin and the drawing buffer to 800 by 600 pixels. Existing lighting and ground rendering may remain.

2. Expose `window.pickingProbe` with `pick(ndcX, ndcY)`, `project(id)`, `state()`, and `reset()`. `pick` must raycast recursively against only `picking-fixture`, using the current camera, and choose the nearest intersection. Resolve a hit to the nearest ancestor having `userData.pickId`. On a hit, return `{id, point:[x,y,z], distance, objectName}`, where `objectName` is the intersected mesh's name, set `SceneRenderer.selectedObjects` to exactly that mesh, and set the diagnostic selected ID accordingly. On a valid miss, return null, clear both selections, and leave `lastError` null.

3. `project(id)` must return the logical group's world position transformed by Three.js `Vector3.project(currentCamera)` as `{x,y,z}`, or null for an unknown ID. Primary-button canvas pointer picks must use the same picking routine and convert coordinates with `x=2*(clientX-rect.left)/rect.width-1` and `y=-2*(clientY-rect.top)/rect.height+1`; ignore pointers outside the canvas rectangle.

4. `state()` returns `{selectedId, lastError, pickCount}`. NDC inputs are valid only when both are finite numbers in the inclusive range [-1,1]. Invalid input returns null, sets `lastError` to `invalid-ndc`, and leaves selection and `pickCount` unchanged. Every accepted API or pointer pick, whether hit or miss, increments `pickCount` by one and clears `lastError`; projection does not change diagnostics.

5. When `SceneRenderer.enableObjectSelection` is false, picking returns null and leaves selection and all diagnostics unchanged. `reset()` clears selection and `lastError`, sets `pickCount` to zero, and restores the initial camera pose and orbit target, but does not alter rendering-quality, material, environment, or ground settings.

6. Keep the probe unavailable outside fixture mode, preserve ordinary viewer behavior there, and use no remote assets, network calls, screenshots, or image-based decisions.
