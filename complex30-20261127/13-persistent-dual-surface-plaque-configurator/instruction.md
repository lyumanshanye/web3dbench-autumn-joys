Build a standalone Three.js browser app called “Plaque Studio.” Use only local starter dependencies, procedural geometry, solid-color materials, and locally generated canvas textures; load no models, images, font files, or remote assets and make no runtime network requests. Expose `window.plaqueStudio` with `scene`, `camera`, `controls`, `panel`, `frontLabel`, `backLabel`, `getState()`, `setSide(side, patch)`, `setBaseColor(hex)`, `selectSide(side)`, `pickAt(clientX, clientY)`, `save()`, `load()`, and `reset()`.

1. Use Y-up world units. Create a full-window canvas, resize handling, OrbitControls with damping, ambient and directional lighting, and a perspective camera with FOV 45, near 0.1, far 100, initially at (6,4,8) looking at (0,1.2,0). Add a 12×12 floor whose top is y=0. Add a box mesh named `panel`, dimensions 4×2.4×0.3, centered at (0,1.4,0); its front faces +Z.

2. Each label is a 1.8×0.6 plane in a group parented to `panel`. `frontLabel` is at local (0,0,0.151) with zero rotation; `backLabel` is at local (0,0,-0.151) with Y rotation π. Display each label’s text using a generated canvas texture. Default state is `{version:1,baseColor:"#4477aa",selected:"front",front:{text:"HELLO",color:"#ffffff",x:0,y:0,rotation:0,scale:1,visible:true},back:{text:"BACK",color:"#ffcc00",x:0,y:0,rotation:0,scale:1,visible:false}}`. Position x/y, Z rotation in degrees, and uniform scale apply to the corresponding label group; visibility controls both the group and its pickability. Base color updates the panel material immediately.

3. `setSide` accepts only `front` or `back` and merges a valid patch into that side. Text must be a string of at most 24 characters; x must be in [-1,1], y in [-0.7,0.7], rotation in [-180,180], scale in [0.5,2], visible must be boolean, and colors must match `#[0-9a-fA-F]{6}`. Reject unknown keys, unknown sides, non-finite numbers, and invalid values: return false without changing state, scene, or storage. Valid calls return true and update the scene immediately. `setBaseColor` follows the same color rule. `selectSide` changes selection only for a valid side. `getState` returns a deep copy.

4. Use localStorage key `plaqueStudio.v1`. `save()` writes the complete current state as JSON and returns true. `load()` validates every field and default-required key, then applies the state and updates all geometry, materials, textures, and visibility, returning true. Malformed JSON, a wrong version, missing keys, or invalid values make `load()` return false while leaving current state and scene unchanged. On startup, automatically load a valid saved state; otherwise use defaults and remove the invalid stored item. Successful edits do not save automatically.

5. `pickAt` raycasts from canvas-relative client coordinates against visible labels only. A hit selects and returns that side (`front` or `back`); a miss returns null and leaves selection unchanged. Provide DOM controls for text, color, x, y, rotation, scale, visibility, side selection, Save, Load, and Reset.

6. `reset()` restores every default state value, rebuilds both label textures, restores the initial camera position and controls target, removes `plaqueStudio.v1`, and returns a deep copy of the default state without reloading the page. Numeric comparisons use tolerance 1e-5.
