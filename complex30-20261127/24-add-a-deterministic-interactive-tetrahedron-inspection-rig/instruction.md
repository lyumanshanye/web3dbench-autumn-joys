Extend the existing TetraFlow browser demo with a procedural 3D inspection rig and deterministic playback controls. Preserve the start button, audio initialization, existing SuperFlow and its children, renderer, lighting, resize handling, and OrbitControls limits.

1. After creating SuperFlow, add a `THREE.Group` named `inspectionRig` directly to the scene at position `(0,0,0)`. Add one `THREE.Mesh` named `inspectionRing` using `TorusGeometry(4, 0.02, 8, 96)`, rotated `Math.PI / 2` about X so the ring lies in the XZ plane. Add exactly eight marker meshes named `marker-0` through `marker-7`, each using its own `TetrahedronGeometry(0.3, 0)` and its own material. For zero-based index `i`, set `a = 2 * Math.PI * i / 8` and local position `(4 * cos(a), 0, 4 * sin(a))`. Use default color `0x40c0c0`; do not merge the markers or make them GPU instances.

2. Replace wall-clock animation time with a simulation-time variable initially equal to `0`. While running, advance it by the clock delta on each animation frame; while paused, do not advance it. Continue calling `superFlow.update(simulationTime)` and rendering while paused. Set `inspectionRig.rotation.y = 0.25 * simulationTime`. For each marker, set `rotation.x = 0.5 * simulationTime + i * Math.PI / 4` and `rotation.z = -0.2 * simulationTime`; marker local positions must remain as specified above.

3. Space toggles between running and paused. While paused, ArrowRight advances simulation time by exactly `0.25` seconds and immediately applies the new transforms; ArrowRight while running has no effect. `R` resets simulation time to `0`, enters the paused state, clears selection, restores the initial camera position using `(0, 2.5, 12).setLength(17)`, sets the OrbitControls target to `(0,0,0)`, and updates controls. Ignore modified key events and auto-repeat events, and prevent ArrowRight from scrolling the page.

4. Implement primary-button pointer picking against only the eight marker meshes using `THREE.Raycaster` and the actual canvas bounding rectangle. A marker hit selects the lowest-index intersected marker, changes only that marker to `0xff8000`, and restores every other marker to `0x40c0c0`. A click that hits no marker clears selection. Add a text element with id `flowStatus` whose content is exactly `Selected marker: none` when none is selected or `Selected marker: i` for marker `i`. Selection must not pause animation or alter marker geometry or transforms.

5. Add a concise on-screen help element describing Space, ArrowRight, R, and marker clicking. Keep orbit and zoom functional, including while paused. Do not add remote assets, network requests, external fixtures, or new dependencies.

6. For automated inspection, expose `window.tetraFlowDiagnostics` after initialization with references `scene`, `camera`, `controls`, `superFlow`, `rig`, and `markers`, plus functions `getSimulationTime()`, `isPaused()`, `step()`, and `reset()`. The `step()` and `reset()` functions must follow the same rules as their keyboard equivalents.
