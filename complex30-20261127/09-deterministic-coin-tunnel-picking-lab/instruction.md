Build a standalone Three.js browser page called “Coin Tunnel Lab.” Use only local starter dependencies and procedural geometry; make no runtime network requests and load no models, textures, fonts, or animation libraries. Use Y-up world units and numeric tolerance 1e-5.

1. Create a full-window scene with background 0x08080c, a PerspectiveCamera (fov 35, near 0.1, far 2000), and two white DirectionalLights of intensity 1.5 at (-1,0,0) and (1,0,0). Add a Group named `tunnel` containing eight coin Groups named `coin-0` through `coin-7`. Each coin must contain a gold MeshStandardMaterial CylinderGeometry(3,3,0.54,16), rotated X by PI/2, and a TorusGeometry(3,0.3,8,64) rim; both face along Z. Add a wireframe, open-ended CylinderGeometry(60,60,400,32,1,true) named `tunnel-shell`, but do not make it pickable.

2. Generate coin paths from this inline `[angle,q,initialProgress]` fixture: `[[0,0,0.10],[Math.PI/4,0.25,0.25],[Math.PI/2,0.5,0.40],[3*Math.PI/4,0.75,0.55],[Math.PI,1,0.70],[5*Math.PI/4,0.125,0.85],[3*Math.PI/2,0.375,0],[7*Math.PI/4,0.625,0.95]]`. For each coin, radius `r=12+48*sqrt(q)`, local position is `(r*cos(angle),200-400*p,r*sin(angle))`, and uniform scale is `min(1,p/0.05)`. Initial coin rotations and tunnel rotation are zero.

3. Expose `window.coinLab` with `scene`, `camera`, `renderer`, `tunnel`, `coins`, `reset()`, `step(n)`, `setProgress(i,p)`, `setView(name)`, `projectCoin(i)`, `pick(ndcX,ndcY)`, and `state()`. `step(n)` advances exactly n fixed steps: every coin gets `p+=0.0015`, rotation X `+=0.06`, and rotation Z `+=0.03`; if `p>1`, subtract 1 and set that coin’s X/Z rotations to zero. Then add 0.00025 to `tunnel.rotation.y` and update positions/scales. Reject non-integer n or n outside 0–10000 with RangeError and no mutation. `setProgress` rejects invalid indices or non-finite p outside [0,1] similarly.

4. `setView("inside")` sets camera up `(0,0,-1)`, position `(0,-200,0)`, and lookAt origin; `setView("overview")` sets up `(0,1,0)`, position `(0,0,650)`, and lookAt origin. Reject other names with RangeError. `projectCoin(i)` returns the coin center’s world-space projected `{x,y,z}` in NDC. `pick` raycasts only coin meshes, selects the nearest hit’s coin, returns its name, and on a miss returns null, sets selected to null, and resets every coin material’s emissive to 0x000000. Selection sets that coin’s materials’ emissive to 0x552200 and all others to 0x000000. Canvas pointer clicks must perform the same pick using canvas-bounds NDC.

5. Render continuously but never advance simulation automatically. Provide Step and Reset buttons plus text readouts for total steps, tunnel rotation, and selected coin. Step calls `step(1)`. `state()` returns `{steps,tunnelRotation,selected,coins:[{name,p,position,scale,rotation}]}` using current local transforms.

6. Reset restores the fixture progress values, zero coin/tunnel rotations, derived positions/scales, zero steps, null selection/emissives, and the inside camera view. It must not recreate geometry or add duplicate objects, lights, listeners, or animation loops.
