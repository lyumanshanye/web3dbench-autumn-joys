Build a standalone Three.js browser page called “Lightning Fracture Lab.” Use only local Three.js/OrbitControls code, procedural BufferGeometry, solid-color materials, and ordinary DOM. Make no runtime network requests and load no models, textures, fonts, audio, shader files, or remote data. Use Y-up world units and expose `window.stormLab` with `generate(seed)`, `strike(seed)`, `step(milliseconds)`, `reset()`, and `getState()`.

1. Render an 800×600 canvas with a perspective camera at `(0,18,55)`, field of view 50 degrees, looking at `(0,12,0)`. Add a 40×40 grid on the XZ plane at `y=0`. The bolt starts at `(0,30,0)` and ends at `(0,0,0)`. Use a white main bolt, cyan branches and crackles, and a white impact sphere. OrbitControls may inspect the scene, but simulation time must advance only through `step`.

2. `generate(seed)` must replace existing effects and construct one deterministic bolt. Use a 32-bit unsigned LCG: `state=(1664525*state+1013904223)>>>0`, beginning with `state=seed>>>0`; each random value is `state/4294967296`. Build the main path by recursive midpoint displacement to depth 4, processing the first half before the second half. At each internal node, consume one random value, set `m=(a+b)/2`, `d=b-a`, `p=normalize((-d.y,d.x,0))`, and replace `m` by `m+p*((random-0.5)*D)`. Initial `D=6`; halve `D` for each child recursion. Keep every main-path z coordinate zero. This yields 17 ordered points and 16 main segments.

3. Add two branches, each a three-point polyline. Branch A runs from main point 4 to that point plus `(-6,-8,2)`, with its midpoint offset by `(0,0,1)`. Branch B runs from main point 8 to that point plus `(5,-6,-2)`, with its midpoint offset by `(0,0,-1)`. Flatten the main path followed by branches A and B into one `THREE.LineSegments` geometry: 20 segments and 40 position vertices. `getState()` must return the seed, main points, segment count, draw-range count, opacity, simulation time, phase, impact scale, and crackle count.

4. Create six ground crackles at `y=0.02`. For `i=0…5`, let `a=i*Math.PI/3`; each has inner point `(2cos(a),0.02,2sin(a))`, outer point `(6cos(a),0.02,6sin(a))`, and midpoint at radius 4 and angle `a+(i%2===0?0.12:-0.12)`. Each crackle contributes two line segments, for 12 total. Add an impact sphere centered at the origin with base radius 1.

5. `strike(seed)` performs `generate(seed)`, hides crackles and sphere, sets time 0 and phase `drawing`, and sets bolt opacity 1. During `0≤t≤400`, reveal `floor(20*clamp(t/400,0,1))` segments and set draw-range count to twice that number. At `t=400`, show all bolt segments, crackles, and sphere. For `400<t<800`, set sphere scale uniformly to `8*sin(Math.PI*(t-400)/400)`. Keep opacity 1 through `t=600`; for `600<t<800`, use `1-(t-600)/200`. At `t≥800`, remove all effects, set phase `idle`, draw-range count and impact scale to 0, and crackle count to 0. Clamp large `step` inputs at the final state.

6. Provide a seed text input plus Generate, Strike, Step 200 ms, and Reset buttons. A valid seed is an integer from 0 through 4294967295. Invalid input must leave the current scene unchanged and display `Invalid seed`; valid actions clear that message. `reset()` removes every effect, restores time 0, phase `idle`, opacity 1, and seed 0, clears the message, and leaves camera and grid unchanged.
