Build a standalone Three.js browser app called “Gizmo Relay Lab.” Use only local starter dependencies, OrbitControls, procedural geometry, and solid-color materials; make no runtime network requests and load no models, textures, fonts, or animation libraries. Use meters, Y-up coordinates, and radians. Expose `window.relayLab` with `scene`, `camera`, `renderer`, `controls`, `pods`, `dock`, `selectedId`, `time`, and the methods below.

1. Create a perspective camera at `(12,10,16)` looking at `(0,0,0)`, OrbitControls with damping disabled, ambient and directional lighting, and a 20-by-20 grid. Add a `dock` Group at `(0,2,-3)` with rotation `(0,Math.PI/2,0)`. Create three pod Groups named `alpha`, `beta`, and `gamma`, initially at `(-4,0.5,0)`, `(0,0.5,0)`, and `(4,0.5,0)`. Each contains a selectable box mesh of dimensions `(2,1,1)` centered at its Group origin and a child cylinder mast of radius `0.15`, height `1`, centered at local `(0,1,0)`. Give the boxes distinct solid colors.

2. Clicking any pod mesh or mast must raycast through descendants, select its ancestor pod, update a text readout to its ID, and place a visible three-axis translation gizmo at that pod’s world position. Implement pointer dragging along one gizmo axis. Also expose `selectPod(id)` and `dragPod(id,axis,delta)`; both interaction paths must use the same transform rule. Dragging changes only the named local position component by `delta`, clamping x to `[-6,6]`, y to `[0,4]`, and z to `[-4,4]`. An unknown ID, an axis other than `x`, `y`, or `z`, or a non-finite delta returns `false` and changes nothing; valid calls return `true`.

3. Expose `dockPod(id)` and `undockPod(id)`. Docking reparents that pod to `dock`, and undocking reparents it directly to `scene`; both must preserve the pod’s world position and world quaternion, using world-transform-preserving attachment rather than copying local coordinates. The gizmo must remain at the selected pod after either operation. Invalid IDs return `false` without mutation.

4. Expose `focusSelected()`. It must immediately set `controls.target` to the selected pod’s world position `p`, set the camera position to `p+(6,4,6)`, and update controls without tweening. Add a Focus button that invokes this method.

5. Expose `seek(t)`, clamping finite input to `[0,4]` and storing it as `time`. At time `t`, set `dock.rotation.y = Math.PI/2 + (Math.PI/2)*(t/4)` and every mast’s `scale.y = 1 + 0.5*Math.sin(Math.PI*t/4)`; other mast scale components remain `1`. Play/Pause may animate continuously, but `seek` must produce these exact poses without depending on frame rate. Non-finite input leaves state unchanged and returns `false`.

6. Provide Dock, Undock, Reset, and Play/Pause controls plus selected-ID and time readouts. `reset()` must stop playback, restore all initial pod parents, positions, rotations and scales, restore the dock transform, set every mast scale to `(1,1,1)`, select `alpha`, set time to `0`, and restore the initial camera and controls target. All numeric comparisons use tolerance `1e-6`.
