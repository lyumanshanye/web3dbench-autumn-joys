Build a standalone Three.js browser app called “Survey Rig Lab.” Use only local starter dependencies, procedural geometry, solid-color materials, and ordinary DOM/JavaScript. Make no runtime network requests and load no models, textures, fonts, or controls libraries. Use meters, Y-up coordinates, radians internally, and numeric tolerance 1e-5. Expose `window.surveyRig` with `scene`, `camera`, `renderer`, `yaw`, `pitch`, `targets`, `setInput(state)`, `step(dt)`, `look(dx,dy,shiftHeld)`, `pickCenter()`, `reset()`, and `getState()`.

1. Create an 800×600 canvas and a `PerspectiveCamera(60, 800/600, 0.1, 200)` whose default forward direction is local -Z. Add `yaw` to the scene at (0,0,0), add `pitch` as its child, and add the camera as pitch's child at local (0,1.6,0). Add a 40×40 ground plane at y=0 and a grid. Create three 1×1×1 box targets with IDs `A`, `B`, and `C`, centered respectively at (0,1.6,-6), (4,1.6,-6), and (-4,1.6,-8). Store them in `targets` in that order.

2. `setInput(state)` replaces the six Boolean flags `forward`, `backward`, `left`, `right`, `up`, and `down`; omitted flags become false. `step(dt)` accepts only finite dt in [0,1], otherwise throws `RangeError` without changing state. For horizontal input, x=right-left and z=backward-forward; normalize (x,z) if its length exceeds 1. Translate yaw locally by `yaw.translateX(4*x*dt)` and `yaw.translateZ(4*z*dt)`. Change camera local y by `2*(up-down)*dt`, clamped to [0.5,4]. Use no inertia, damping, gravity, or automatic simulation advancement.

3. `look(dx,dy,shiftHeld)` does nothing when `shiftHeld` is false. Otherwise apply `yaw.rotation.y -= dx*0.002` and `pitch.rotation.x -= dy*0.002`, then clamp pitch to [-Math.PI/2,Math.PI/2]. Nonfinite dx or dy throws `TypeError` without changing either rotation. Bind WASD to horizontal flags, E/Q to up/down, and Shift+mousemove to the same look formula; keyboard flags change only on key events, and movement advances only through `step`.

4. `pickCenter()` raycasts from the camera through canvas NDC (0,0), intersects only the three target meshes, and returns null for no hit. Otherwise return `{id, point:[x,y,z], distance}` for the nearest hit and set that target's material color to 0xffcc00; restore every other target to 0x3388ff. Ground and grid must never be pickable.

5. `getState()` returns fresh data containing `yawPosition` as an array, `yawAngle`, `pitchAngle`, `eyeHeight`, all six input flags, and `selectedId`. `reset()` restores the exact initial transforms and target colors, clears all flags and selection, and leaves the renderer and scene objects in place. Provide Reset and Step buttons; Step calls `step(1/60)`. Show text readouts for yaw, pitch, eye height, and selected ID.

6. A render loop may render continuously but must not call `step` or otherwise advance movement. Resize handling must update camera aspect and renderer size without altering rig transforms. All API results must be deterministic and independent of frame rate.
