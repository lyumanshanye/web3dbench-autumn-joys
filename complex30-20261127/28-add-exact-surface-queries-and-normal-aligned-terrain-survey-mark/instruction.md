Extend the existing A-Frame terrain project without replacing its procedural terrain, shader, primitive mappings, or existing getElevation behavior.

1. Add a geometry-data method getSurfaceInfo(x, z) beside getElevation. It must query the actual indexed BufferGeometry, not regenerate noise. Project each indexed triangle onto XZ and, for the triangle containing the query point, compute barycentric weights using signed twice-areas: w0=A(P,B,C)/A(A,B,C), w1=A(P,A,C)/A(B,A,C), and w2=1-w0-w1. Accept weights down to -1e-8 and clamp accepted weights to [0,1] before renormalizing. Return {elevation, normal}, where elevation is the barycentric interpolation of the three position.y values and normal is a new THREE.Vector3 containing the normalized barycentric interpolation of their normals. If no triangle contains the point, return elevation 0 and normal (0,1,0). Shared-edge results must not depend on triangle traversal order.

2. Register a terrain-survey component usable on a-atoll-terrain. Its schema is radius (default 5), count (default 8), height (default 2), and markerRadius (default 0.2). On initialization, create one THREE.Group named survey-group containing count cylinder meshes named <component-id>-marker-k for k=0..count-1. For each marker, use angle=2*Math.PI*k/count, x=radius*cos(angle), and z=radius*sin(angle). Query getSurfaceInfo(x,z), put the cylinder base at (x,elevation,z) in terrain-local coordinates, align cylinder local +Y to the returned normal with setFromUnitVectors, and place its center at base + normal*(height/2). Use CylinderGeometry(markerRadius,markerRadius,height,12) and any vertex-color-compatible opaque material; no textures or remote assets.

3. When survey attributes update, rebuild only that component's marker group and dispose replaced marker geometries and materials. Do not regenerate or replace the terrain BufferGeometry. Sanitize updates as follows: non-finite radius, height, or markerRadius uses its default; finite radius is clamped to [0,10000], height to [0.1,100], and markerRadius to [0.01,10]. Count is rounded, clamped to [1,64], and non-finite count uses 8.

4. Add a deterministic demonstration to example.html using terrain id survey-terrain with seed="0.25", plateau-radius="6", plateau-elevation="2", middle-radius="20", unit-size="1", and far="80". Attach terrain-survey with id inner-survey, radius 4, count 8, height 2, and markerRadius 0.2. Add a second survey with id outer-survey, radius 30, count 4, height 3, and markerRadius 0.25. Keep the existing camera and movement controls usable.

5. Keep all coordinates in meters and all survey objects in the terrain entity's local space. The inner markers must therefore have base elevation 2 and center Y 3, while outer markers have base elevation 0 and center Y 1.5. Do not alter terrain seed, vertex positions, colors, or wave behavior when adding or updating surveys.
