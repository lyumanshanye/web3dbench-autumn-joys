Build a standalone Three.js browser page called “Panorama Dwell Relay Lab.” Use only locally available Three.js code and procedural geometry/materials; load no images, models, fonts, controls libraries, or remote assets and make no runtime network requests. Use Y-up world units and expose `window.relayLab` with `scene`, `camera`, `renderer`, `rooms`, `markers`, `pick`, `setView`, `setDwell`, `step`, `activate`, `reset`, and `getState`.

1. Create a full-window scene and `PerspectiveCamera(60, aspect, 0.1, 1000)` at `(0,0,0)`. Add a radius-100 sphere with `BackSide` material as a non-pickable enclosure. Create room groups `A` and `B`, with only the current room visible. Each marker is a radius-2 `SphereGeometry(2,16,12)` mesh at distance 40 from the origin. Room A contains `alpha:(40,0,0)`, `beta:(0,20,-34.64101615137755)`, and `exit:(0,0,-40)`. Room B contains `return:(0,0,40)` and `target:(-40,0,0)`. Give markers distinct solid colors and set each mesh's `name` and `userData.id` to its ID.

2. Define view angles in degrees by `forward=(sin(yaw)*cos(pitch), sin(pitch), -cos(yaw)*cos(pitch))`, with the camera looking from the origin along that vector. Initial and reset view is yaw 0, pitch 0. `setView(yaw,pitch)` normalizes yaw to `[-180,180)`, clamps pitch to `[-80,80]`, updates the camera, and returns true. Non-finite inputs return false without changing state.

3. `pick(ndcX,ndcY)` raycasts only visible marker meshes, ignoring the enclosure and hidden room, and returns the nearest marker ID or null. Non-finite coordinates or coordinates outside `[-1,1]` return null. Picking alone must not activate anything. `activate(id)` returns false for an unknown or non-current-room ID; otherwise it records the ID in `activations`. For `alpha`, `beta`, and `target`, immediately aim at the marker using `yaw=atan2(x,-z)` and `pitch=asin(y/40)`, both converted to degrees. Activating `exit` selects room B and resets yaw/pitch to 0; activating `return` selects room A and resets yaw/pitch to 0.

4. Implement center-screen dwell selection without wall-clock timers. `setDwell(boolean)` enables or disables dwell and clears `dwellId` and `dwellMs`. While enabled, `step(ms)` picks at NDC `(0,0)`, accumulates milliseconds only while the same marker remains centered, and resets accumulation to zero whenever the centered ID changes or is null. At `dwellMs >= 1000`, activate that marker once, then disable dwell and clear dwell progress. Ignore negative or non-finite step durations.

5. `getState()` returns `{room,yaw,pitch,dwellEnabled,dwellId,dwellMs,activations}` with activation IDs in chronological order. `reset()` restores room A, yaw/pitch 0, disabled and cleared dwell, and an empty activation history; it must not recreate geometry or reset canvas size. Render continuously and resize the camera and renderer with the window.

6. Provide small text readouts for room, yaw, pitch, dwell ID/progress, and activation history, plus Reset and Dwell buttons. Pointer clicks on the canvas may call `pick` and `activate`, but all behavior must also be deterministic through the exposed API. Numeric comparisons use tolerance `1e-4`.
